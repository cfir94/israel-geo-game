# assets

`icon.png` — אייקון המשחק שמופיע לצד הכותרת במסך הבית.

מעלים לכאן קובץ בשם המדויק `icon.png`, רצוי מרובע (512×512 ומעלה).
אם הקובץ חסר, הכותרת נופלת חזרה לאימוג'י 🗺️ ושום דבר לא נשבר.

להעלאה מהדפדפן: בגיטהאב → תיקיית `assets` → `Add file` → `Upload files`
→ גוררים את התמונה → `Commit changes`.
